# 聚宝盆玩家指南

完整解压 Windows 包，打开 `TokenGame.exe`。无需打开浏览器，也无需安装 TokenTracker。

## 收菜

- 左键单击聚宝盆：回弹后收取 Token，显示本次收入。空盆同样回应，显示 +0，不虚构收益。
- 左键双击或右键：打开收获与武器窗口，不收取。
- 按住拖动：调整桌面位置，不触发收菜。
- 托盘：显示、隐藏聚宝盆，打开窗口或退出。
- 关闭收获窗口不会停止采集；托盘退出才会结束应用。

聚宝盆平时轻轻浮动，有新用量时短暂提示。尊重系统减少动画偏好，无自动音效或催促弹窗。
单击立即回弹，实际收取等待 500 毫秒，以给双击留下取消单击的时间。

新增用量自动保存到待收区；收取后成为可用 Token。累计和今日统计不会因为抽取消费而减少。

## 祈器

一次消耗 100,000 Token，十次消耗 1,000,000，单抽和十连共享规则，无折扣或十连专属概率。
十次按钮更突出；按钮显示 100K / 1M Token，可用、待收、今日和累计也使用英文 K / M / B 缩写。悬停数值可查看完整数字，缩写不影响扣费或余额。

| 品级 | 基础概率 | 武器数量 |
| --- | ---: | ---: |
| 凡品（白） | 75% | 3 |
| 良品（绿） | 20% | 3 |
| 上品（蓝） | 4.5% | 3 |
| 极品（紫） | 0.4% | 3 |
| 仙品（金） | 0.1% | 3 |

连续 20 抽内至少获得一次上品及以上，1000 抽内至少获得一次仙品。提前获得会重置对应计数；重启不会重置保底。界面内的概率按钮可查看完整规则。
只抽武器，没有经验、货币等混合奖池；不主动调用模型制造 Token。

## 分解与兑换

「分解 · 兑换」默认显示全部 15 把武器及持有数量，点击图片查看、兑换，不显示勾选框。点击「批量分解」后进入选择模式，单击卡片切换选择，选中后整张变暗并显示勾；没有持有的武器不可选。
长按约 350 毫秒后拖动，可连续选中过路卡片；从已选卡片开始长按拖动，则连续取消。选择模式内可全选，或在品质菜单中选择仅凡品、凡品加良品、凡品加良品加上品。键盘空格/回车也能切换当前卡片。
预览总把数和玄铁收入后，一次确认分解所选种类的全部持有数量，包括最后一把；含仙品会特别提醒。成功后返回普通浏览模式。退出选择不修改库存，Esc 先取消确认，再退出选择。没有默认勾选或自动分解。

| 品级 | 每把分解所得玄铁 | 兑换指定武器 |
| --- | ---: | ---: |
| 凡品 | 1 | 12 |
| 良品 | 3 | 36 |
| 上品 | 8 | 120 |
| 极品 | 25 | 400 |
| 仙品 | 100 | 6,000 |

兑换得到的是所选武器，不是再抽一次；不影响祈器保底。

按每天 750 万 Token、保留仙品并把其他武器全部分解兑换仙品计算，长期平均约 7 天获得一把仙品；每天 500 万约 10.5 天，每天 1000 万约 5.2 天。只抽不兑换时平均约 8.5 天（750 万/天）。这是长期统计，不是每周必得；起始没有材料时，第一把与后续兑换节奏也不同。

## 日志与存档

默认读取 `CODEX_HOME` 或用户目录的 `.codex`。窗口底部「连接」使用系统选择器修改目录。当前只支持本机可读的 Codex 日志，不自动包含其他电脑、云端或其他 Agent。

首次连接只建立基线，不灌入安装前历史；后续退出期间的记录会在重启补采。今日统计按事件时间与本地日期计算。

v1 聚宝盆存档升级前保存 `.pre-weapons.bak`；此前已收取 Token 自动变成可用余额，待收量不变，不重复发放。
更老的 `ledger.json` 总量仍单独保留，不作为新的可消费 Token。
2026-10-30 调整不会回收旧武器、材料或余额，也不会重置已有保底计数；此后的抽取和兑换执行新数值。
