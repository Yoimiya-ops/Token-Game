# 需求文档

## 产品目标

Token Game 把真实 LLM token 消耗变成一套轻量挂机游戏。用户启动应用后先看到桌面小宠物，再通过双击桌宠进入游戏界面查看 token 收益、猫粮和升级进度。

## 用户角色

- 普通玩家：希望桌面上有一个可互动桌宠，并把自己的 token 使用变成游戏资源。
- 开发者：希望拉取代码后可以在 macOS 或 Windows 上快速启动、调试和打包。

## 核心需求

### R1 桌宠启动体验

- 应用启动后默认显示桌宠窗口。
- 桌宠窗口透明、无边框、默认置顶、可拖动。
- 单击桌宠触发互动动画和气泡文案。
- 双击桌宠打开游戏窗口。
- 右键桌宠打开管理菜单。
- 桌宠可以隐藏到系统托盘，并可从托盘恢复。

### R2 桌宠资源管理

- 内置桌宠资源库包含默认白猫动图和其他角色。
- 默认桌宠不可删除，作为兜底资源。
- 非默认内置资源可以删除；删除后从用户资源列表隐藏。
- 内置资源可以重命名；名称保存在用户数据中。
- 用户可以导入图片资源作为自定义桌宠。
- 支持导入格式：png、jpg、jpeg、webp、gif、apng。
- 自定义桌宠可以重命名和删除。
- 删除自定义桌宠时，需要删除应用保存的图片文件和元数据。

### R3 游戏界面

- 游戏窗口显示小猫名称、猫粮、总 token、上次喂食时间、处理器等级、累计消耗猫粮。
- 用户可以手动触发 token 同步。
- 用户可以消耗猫粮升级处理器。
- 猫粮不足时，升级接口返回错误，前端展示错误信息。
- 最近 token 事件列表展示 token 类型、token 数量和猫粮收益。

### R4 TokenTracker 接入

- 应用使用 `tokentracker-cli` 接入 mm7894215/TokenTracker。
- 应用读取 `~/.tokentracker/tracker/queue.jsonl`。
- 支持 input、cached、output、reasoning 四类 token。
- 应用只把新增 token delta 计入账本，避免重复结算。
- 启动时清理历史 mock 事件，保证收益来自真实 TokenTracker 数据。
- TokenTracker 未安装或队列不存在时，应用仍可启动。

### R5 跨平台启动

- macOS 和 Windows 开发者都可以通过 `corepack pnpm start` 启动桌面应用。
- macOS 可以生成 `.app`。
- Windows 可以生成 `.exe` 包目录。
- 启动和打包步骤必须在文档中明确。

## 非目标

- 不做云端账号系统。
- 不做多人同步。
- 不把打包产物提交到 Git。
- 不在运行时物理删除内置素材文件。

## 成功标准

- 新开发者按 README 执行命令后，可以打开桌宠和游戏窗口。
- `GET /` 返回游戏页面。
- `GET /api/state` 能返回游戏状态。
- 桌宠导入、切换、重命名、删除逻辑可用。
- 测试和类型检查通过。
