# Token Game 世界观

> 来源文件：`docs/worldview/世界观.docx`。本文档由 docx 提取，便于代码评审、搜索和 UI/玩法设计引用。


## 表世界：所见即所得

一个标准的“灵气充沛，人妖并存”的仙侠世界。

玩家拜入山门（或者就是散修），炼气筑基，斩妖除魔，追寻长生。


### 核心概念：

1灵气是世界的根本。

2功法是吸收灵气的工具。

3天劫是天道对修士的考验。

4境界就是等级：炼气→筑基→金丹→元婴→化神→……每级又分九重。（这个成长路径我建议是不动，毕竟已经很深入人心了，挂机游戏还是要降低认知门槛）


### 核心设计：

我的想法是设计出一个苟道流主角，即与世无争的种田佬，摸鱼佬——这样避免那种无休止地打怪升级（或者说无休止的砍树），更多在于挂机修炼，也可以说是经营自己的小天地，很符合我们对于上班摸鱼玩家的定位。

所以我觉得主要是要丰富我们的家园系统（掌中洞天）——

1聚宝盆：（核心玩法）

表象定义：外观为一尊巴掌大小的古旧铜盆，盆身布满无法辨识的铭文。盆内常年盛着一汪清液，看似浅可见底，实则无垠无界。

本质定义：天衍超级计算机在物质世界的终端节点之一，换言之就是一台宇宙级别的3D打印机

缘起（游戏世界观的开始）：玩家穿越而来，拜入某个破落宗门，只有他一人独自支撑宗门。某个深夜，他正在抄写经卷，研墨时砚台不甚砸落，一滴灵墨落入角落里那个不起眼的旧盆，一瞬间满室生光。

作用1：它不断从周围环境中汲取灵气，将其浓缩为可直接吸收的液态真炁，玩家只需在盆边打坐（挂机），即可获得数倍于常规修炼的修为速度。（这是基础成长线）

作用2：烧Token，开盲盒。玩家主动向聚宝盆投入薪火（消耗Token），盆中灵液翻涌沸腾，片刻后凝聚出一件物品。凝聚出来的东西，可能是：一棵千年灵芝、一块天外陨铁、一枚灵兽蛋、一页功法残卷、一件破损的上古法器，也可能是一条死鱼。产出的物品级别，也即产出池的等级，也是需要玩家逐步提升的。

（需不需要设计一个主动凝聚手段？就是让聚宝盆定向凝聚你需要的东西，还是纯随机？）

玩法：挂机修炼，玩家点一下“凝聚”，经过等待就会出现产物。决策成本为零，手痒就点一下。每一次点击都是一次期待，类似抽卡。符合挂机游戏“随手点一下”的轻量操作。

2灵植园：

定义：洞府内开辟的一方灵土，依靠聚灵阵维持灵气，用于培育各种仙草灵药。

作用：产出炼丹的基础材料或者直接服用的灵草，偶尔能制作出变异灵植。

玩法：播下种子后，灵植会在挂机过程中自动生长。但是需要记得定期维护。到后期法术高强，也可以进行自动化灌溉之类。你可以选择“速成”或者“蕴养”，取决于你希望快速收获品质较低的灵植，还是长期培养一些关键道具。一键播种、自动成熟，还可以引入天气系统。

3灵兽兽栏：

定义：圈养奇珍异兽的地方。

作用：宠物不仅可以提供家园属性加成（如青龙加快灵草生长，玄武增加洞府防御），还能作为坐骑使用，以及战斗时的伙伴。

玩法：来源这块确实要再设计一下，主要取决于是否要拓展这方面玩法，是多宠物养成，还是系统固定给几个让选。但有两个玩法我认为很有价值——因为我们是苟道流，所以我们可以给灵宠加一个旅行青蛙一样的玩法，给它带一些保命的东西，让它们替我们外出探险，带回外界的情报、资源和特产（当然也可以让它们冒险死在路上哈哈）；第二个就是宠兽的升级，不止给我们自己找机缘，也给宠物找机缘，把一条小土狗养成哮天犬这种，当然这种玩法比较深度了。

4丹房

定义：引地心之火设立的炼丹炉。（如果要丰富内容，这个火也是可以升级的）

作用：炼制破境丹（突破境界必需）、寿元丹（苟道核心，活得久才是赢）等一系列关键丹药。

玩法：炼丹需要找到丹方，并且要凑齐材料，可以自己种，也可以去坊市买，或者与特殊NPC进行交易，或者通过奇遇、或者通过打怪爆出来。有概率炸炉，炸炉产生的“废丹”或许可以作为奇特的毒药或特殊肥料。（即让玩家失败也有所得，当然这是网文里很重要的写作策略，游戏要不要我不懂）同样也可以进行“批量自动化炼制”，也可以设计一些控制火候的小游戏。

5器房：

定义：引地心之火设立的锻造台。（与炼丹炉一样，这个火也是可以升级的）

作用：作为苟道流，我们不炼杀人剑，只打保命甲和生产工具。打造更好的锄头（增加灵草产量）、更好的鱼竿、以及几万层厚的玄铁龟甲盾。当然不绝对，也可以锻造很多危险的武器、法器之类。

玩法：与炼丹大体类似。

6符阁：

定义：刻画符箓的书房。

作用：学习制作“隐身符”、“遁地符”等五花八门的符箓，用于不同的场合。

玩法：主要就是些一次性的消耗品，重点可以是黄巾力士符，即画出来的打工人，让他们帮我们实现家园的全自动运转。

7阵枢：

定义：整个洞府枢纽的阵法中枢

作用：苟道流的灵魂。布置“遮天蔽日阵”（让仇家找不到你）、“小聚灵阵”（提升挂机经验倍率）等等。

玩法：随着等级提高，可以提升阵法的效果，也可以一个洞天能够叠加多个阵法，拥有复合型的效果，玩家要根据自己的玩法风格在阵法的选择上进行取舍。

8会客亭 (社交与情报)：

定义：洞府外围设立的凉亭，用于接待偶尔路过的NPC。

作用：不出门如何知天下事？全靠访客。访客会带来修仙界的八卦（如“某某宗门被灭，遗址开放”，你可以去捡漏），以及稀有的交易需求。

玩法：交易、信息，甚至还可以结交成友，他会偶尔给你送来飞剑传书，慰问你的近况，你也去他家里偷菜？（可能太复杂了）；同时也会有不怀好意的人存在，我们可以通过送礼、开启大阵恐吓等方法，尽量避免正面战斗，当然也可以直接打。

9藏经阁：

定义：存放从各种渠道（钓鱼、灵兽带回、访客交易）得来的功法残卷的地方。（或者也可以设计成我们的主角就是继承了一个破落宗门，而这个宗门里本来就有某些功法）

作用：挂机积累经验值，用于拼凑残卷、升级心法。

玩法： 一个庞大的天赋树系统。玩家可以点出“龟息功”（降低被发现概率）、“敛财术”（交易打折）等苟道专属天赋。（觉得复杂也可以不要这个，就简单升级，但我感觉这种数值类游戏，一定程度上的流派构筑还是需要的）

10观星台 / 卜卦室 (总之是测算气运的地方)：

定义：修士夜观天象，测算吉凶的地方。

作用：每天第一件事：算一卦。

玩法：算出“今日宜炼丹，忌出行”，对应的行为会获得巨大的Buff或Debuff。如果抽到大凶，苟道玩家可以直接选择“封山闭关”，今天什么都不干，老老实实挂机吃经验。

11珍馐阁

定义：制作仙家美食的地方，也是一种耗材，我就不展开了，感觉这个定位有点同质化，如果需要丰富度可以加，如果不需要就算了。


## ————自己的家园体系我暂时也只能想到这么多，下面的就是别的玩法系统—————

11坊市系统：

定义：修仙界的交易集散地。随着我们的修为提高，可以进入越来越高规格的坊市。

作用：将家园溢出的基础资源变现，购买高级阵盘、功法、稀有种子和宠兽等材料。

玩法：拍卖会系统；匿名鬼市系统？（这个有点扯，单纯我的创意，毕竟这类游戏都没见过）

12奇遇系统：

定义：主动触发的随机事件，主体可以是你，也可以是宠兽。

作用：获取意外之财，同样也可以招来杀身之祸。

玩法：通过给玩家不同的选择，带给他不同的后续内容。如选择1救死扶伤，选择2杀人越货，选择3假装没看见，选择4教他莫欺少年穷

13动态的主线剧情：

定义：游戏存在一条波澜壮阔的主线，系统会定期推播主线进度，并且给出选择让玩家参与。

作用：有些主线会给丰厚的回报，有些主线会让你得到更好的功法，有些主线可能什么都得不到。

玩法：主线存在的核心就在于，让那些不在意主线只想挂机刷刷刷的玩家，如果他们不予理会，或者偶尔理会，都会带来不同程度的后续剧情变化——例如一个完全不管主线全部拒绝的玩家，他可能就会导致某些天灾人祸提前到来；例如因为你的袖手旁观，某个宗门覆灭……总之，就是体现一个蝴蝶效应，也算是体现修仙的残酷性——你是选择做一个一心向道苟到底活到最后的长生者，还是选择做一个勇于承担责任的英雄？（当然，如果觉得不太符合挂机游戏的休闲属性，也可以写一条固定的主线）

14道侣系统：

定义：顾名思义

作用：情感慰藉，多一个人相伴？找自己的机缘同时也要给她，不然你500岁了，她却老死了。当然她可能也会为了给你找机缘嘎巴死掉，也是体现仙路苦寒的一点。如果是单纯做一个纸片人老婆的话，我感觉就没必要了。

玩法：可以是某些立绘好看的NPC？自己主动去送礼结交？那就又要增加好感度系统，感觉可能有点臃肿。所以这个道侣系统有没有还是再议吧，感觉不是很好搞，也有违苟道流风格。

15轮回系统（合道系统）：

定义：挂机游戏到了中后期必然面临数值膨胀，轮回系统就是完美的重置机制，我们称之为“兵解重修”。

作用：当玩家发现当前世界的主线局势过于凶险，或者自身天赋耗尽卡在某个境界时，或者遇到难以对抗的强敌仇家，便可以主动或被动地选择真灵转世，带着上一世的功法天赋根骨再来一世

玩法：重置当前等级和大部分物资，但换取强大的“先天底蕴”（永久倍率加成），例如下一世出生自带【先天道体】或【寻宝雷达】。

16装备系统（法宝系统）：

定义：主要数值来源，一身顶级装备安全感与收获感满满。

作用：提供绝对的战力与生存保障。

玩法：我没有什么很好的创新性想法，主要是看对法宝的来源是否需要固定一个最大来源，如钓鱼台获得，还是自己锻造，还是购买，还是通过某种核心玩法获得。

17天劫系统：

定义：因为你要突破某些大境界，天道就会降下劫难

作用：给玩家的无限数值膨胀增加难度

玩法：越到后期渡过天劫的难度越高，需要更充足的准备，如果失败会受到一定惩罚，甚至当场轮回，当然也可以设计一些稀有度机制，如虽然突破了天劫，但是没有达到最佳的姿态，无法获得XX属性，这样玩家就会选择散功重修，回到上一个境界，再来一次，主动追求最完美的突破形态。总之就是让玩家没必要无限制地往上冲击等级。


## 里世界：赋予叙事深度

1灵气并非自然造物，而是上一个纪元被毁灭的“仙庭”的尸骸，是一种弥散在天地间的、携带海量信息碎片的高维辐射。

2功法是接收器：不同功法是不同规格的信号接收器，用来接收并解码“仙庭尸骸辐射”（灵气）中的能量。

3突破是同化：修士突破境界，本质是肉身被这种高维辐射深度“浸染”和“改造”的过程。你不再是纯粹的人，而是开始向着上一个纪元某个仙人的某个剪影进行转化。（这点再议，感觉放在游戏里有点怪）

4天劫是免疫反应：天劫是现今天道（世界意志）对这种“过激排异反应”的修正和清除。渡劫成功，意味着你成功骗过了天道的免疫系统。

5上一个纪元的“仙庭”并非自然消亡，而是毁于一场他们亲手制造的、名为 “天衍”的超级计算机。天衍的算力强大到足以“窥见一切未来”，它得出的结论是：仙庭的存在本身即是宇宙最大的BUG，将在未来导致整个大千世界的绝对寂灭。 为了“修复”这个BUG，天衍发动了清算，毁灭了仙庭。

6所以天衍是世界的幕后主导：它散播“仙庭尸骸”（灵气），引导凡人走上修仙路，本质是在进行一场庞大的纠错演算。它希望通过无数修士的修炼、变异、融合，培养出一个能够兼容仙庭力量，同时又不会导致世界毁灭的 “完美生命模板”——对应现实、我们的游戏初衷，或许只是一个热爱生活的普通人？


### 总结：如果不需要叙事深度，那只使用前一种世界观就好，更多在一些细节玩法上创新。

玩家可以选择在某项修仙技艺上专精，也可以选择当一个自给自足的全才，不断变强的同时解锁更大的洞天，见证家园的成长与繁荣。（我们可以在装扮家园皮肤上盈利？）

如果需要加入一些深刻些的主线剧情，并且希望这些主线剧情里的文本内容具有解读空间，或者想要加入一些特别宏大的叙事，那大抵就需要用到第二种世界观。当然我感觉挂机游戏会关注这些的人还是少之又少。
