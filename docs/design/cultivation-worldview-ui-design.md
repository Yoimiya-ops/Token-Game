# 世界观 UI 设计说明

来源：`docs/worldview/世界观.docx` 与 `docs/worldview/worldview.md`。

## 设计定位

Token Game 的修仙版本应从“菜单式小游戏”升级为“掌中洞天经营界面”。玩家的主身份不是战斗狂，而是苟道流洞府主人：挂机修炼、种田炼丹、布阵避祸、偶尔用聚宝盆烧 Token 凝聚物品。

## UI 原则

- 第一屏是洞府，不是功能表。
- 聚宝盆是核心按钮，承担 Token 消耗、抽取、资源转化的心跳。
- 建筑入口代表玩法系统：灵植园、丹房、兽栏、阵枢、藏经阁、观星台、会客亭、坊市。
- 每个玩法界面只保留一个明确主操作，降低摸鱼玩家的决策成本。
- 表层使用墨绿、铜金、玉色的古典修仙视觉；里层用天衍蓝、扫描线、天机噪声表达“超级计算机”的暗线。
