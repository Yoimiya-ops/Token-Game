苟道修仙，不出洞府也能问鼎长生

这套 UI 把“掌中洞天”作为第一屏：玩家不是在菜单里找功能，而是在自己的洞府里点建筑。聚宝盆是核心心跳，Token 消耗被包装成“投入薪火、凝聚万物”，家园建筑承载种田、炼丹、灵兽、阵法、功法与情报。

低决策成本

随手点一下、挂机等待、收获惊喜，符合摸鱼玩家。

苟道安全感

阵法、防具、封山闭关都要被 UI 明确表达。

表里双层叙事

表层古典修仙，暗层天衍计算机以“天机噪声”露出。

视觉关键词

墨绿洞府、铜金铭文、玉色灵液、朱砂警示。

布局原则

桌面端用三栏：角色/洞府/资源；移动端转为底部建筑导航。

核心动效

灵液翻涌、阵纹点亮、天机读取时短暂遮罩。

交互原则

每屏一个主按钮，其他操作放到建筑详情里。

菜单结构建议

主界面不再放普通 Tab，而是洞府建筑地图。一级入口为：聚宝盆、灵植园、丹房、器房、符阁、阵枢、兽栏、藏经阁、观星台、会客亭、坊市、奇遇。当前版本可以先实现聚宝盆、灵植园、丹房、阵枢、观星台五个核心入口，其他入口用“待修复建筑”呈现，既保留世界观，又不把 MVP 做爆。
