# Feed-the-Kitty-Some-Tokens

An idle game that automatically monitors your backend token usage to feed your own exclusive kitten.

## Project Documents

- [Technical Stack](docs/tech-stack.md)
- [Development Workflow](docs/workflow.md)

## Current Direction

This project is an idle/incremental game where tracked LLM token consumption becomes in-game resources.
The first milestone is to build a reliable token ingestion pipeline, a deterministic offline progression model,
and a minimal playable loop that proves the resource economy.
